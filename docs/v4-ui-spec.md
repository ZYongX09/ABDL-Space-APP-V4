# V4 UI / 信息架构规格（实现基准）

基调：酷安骨架（暗色卡片流 + 悬浮胶囊底栏 + 居中发布键）+ 液态玻璃特色 + ABDL 婴儿蓝。
导航：底部 5 Tab = **首页 / 发现 / ＋发布 / 消息 / 我的**；每 Tab 独立回退栈（切 Tab 保存/恢复，酷安行为）。

## 启动链

Splash 品牌页（≤1.2s，可点跳过）→ 应用锁门（PIN/生物，若有）→ 主壳。
深链：`abdl-space://oauth`（登录回调）、`https://abdl-space.top/qr-login`、`/profile/{id}`、通知点击路由。

## Tab 1 首页

- 顶栏：液态玻璃。左：搜索胶囊（进入全局搜索）；右：公告/铃铛。
- 页签行（tabBarHeight）：用户可编辑的时间线页签 = 聚合 / 关注 / 热门 / 省份 / NBW / 交友宇宙 / 自定义列表/标签；「编辑」入口管理顺序与开关。左右横滑切换（Pager），页签滚动居中。
- 内容：信息流卡片流（规格见 tokens §5），Paging 3 分页、下拉刷新；曝光打点照旧。
- 右下：折扇 FAB 即底栏中央发布键（首页内也可从底栏触发），扇形菜单：发帖 / 交友申请 / 扩列卡 / 相册 / 小说 / 扫一扫。
- 广告卡（服务端注入 advertisement 字段）、彩色徽章弹窗（冷启动）、服务公告条均保留。

## Tab 2 发现

- 顶部搜索胶囊（全局搜索：帖子/用户/话题）。
- 宫格入口（4 列，surface 卡）：交友地图 / 扩列卡 / 纸尿裤评价 / 小说 / NBW 广场 / 扫一扫 / 省份时间线 / 话题广场。
- 下方：推荐内容流（复用信息流卡片）+ 热门话题横滑条。

## ＋发布（底栏中央）

- 点按 = 直接进发帖页（酷安行为）。
- 长按/上滑 = 折扇展开六项（同首页 FAB），玻璃底 + spring 动画。
- 发帖页（全屏）：文本、媒体（≤9 图/视频，上传进度内联）、投票、定时、敏感标记、alt 文本、NSFW 本地预检、NBW 两级级联分类（miuix 菜单，AI 默认回退 FID18 需一次同意）、扩列卡关联、可见范围。发布不等 NBW（静默 receipt 语义平移）。

## Tab 3 消息

- 页签：**私信 / 通知 / 互动**（评论/赞/提及聚合）。
- 私信 = 自研 IM（/messages 协议）：会话列表（头像、摘要、时间、未读角标）；会话页气泡流 + 输入栏（玻璃）；clientMsgId 重试防重、断线重连（stopped 标记修复）、typing、已读。
- 通知 = Mastodon 通知列表（4.x 策略/请求过滤保留）；推送 = JPush（regId 上报、点击路由）。

## Tab 4 我的（酷安「我的」页结构）

1. 头部卡：头像 64dp + 用户名 + 等级/徽章 + 「>」进资料编辑；背景可挂赞助者颜色。
2. 统计宫格：动态 / 关注 / 粉丝（横向三列，点击进列表）。
3. 功能宫格（两行 4 列）：我的收藏 / 浏览历史 / 我的相册 / 宝宝认证 ‖ 赞助中心 / 扩列卡 / 我的 NBW / 更多。
4. 「我的卡片」区：我关注的扩列卡横滑（点击进详情）。
5. 设置入口（右上齿轮）→ 设置域（账户/隐私/外观深浅色/通知/关于，统一 Compose）。
6. 个人主页（他人视角）：四页签 = 相册 / 帖子 / 关于 / 收藏；二维码名片；关注/私信/举报操作。

## Tab 内二级页面映射（全部全屏推入，玻璃顶栏+返回）

- 交友地图：地图为底、玻璃覆盖层（顶栏 + 底部 sheet）；双 SDK（百度/高德）抽象沿用；赞助者门槛保留。
- 扩列卡：广场 hub（双 tab）→ 详情（玻璃卡）→ 编辑器；社交账号绑定 + 可见范围。
- 纸尿裤：列表 / 详情 / 评分 / 榜单。
- 小说：书库 / 书城 / 创作台；阅读器（reader-core）。
- 相册：列表 → 相册详情（九宫格+评论）→ 上传（COS 状态机）；邀请链接。
- 赞助中心：catalog / 颜色 / 兑换 / 感谢墙 / 历史。
- 宝宝认证：活体采集 → 提交 → 证书（验真二维码）。

## 状态与反馈规范（继承 UX 计划三批目标）

- 统一加载/空/错误组件：骨架屏（信息流）、插画空态（发现宫格下内容）、错误卡带重试。
- 弱网：Paging 失败页脚重试；发布失败本地草稿保留。
- 杀进程恢复：IM 未发送重试、相册上传状态机恢复（幂等 UUID 沿用）。
- 无障碍：48dp 触控、4.5:1 对比、字号 100–200% 不裁切、TalkBack 语义。

## 验收方式

- 关键页（首页信息流 / 我的 / 底栏 / 发现 / 消息 / 发帖）在模拟器截图，与本文档 tokens 及参考截图对照（色值/圆角/间距走查）+ 既有测试门禁；真机验收矩阵在 Phase 9。
